The MCP App, end to end

One npm package serves three host surfaces: a widget for MCP Apps hosts, aligned text for everyone else, and a dev harness that impersonates the host.

NEW FILES · V0.3.0

What was added

  • lib/mcp.js — server, 3 tools, capability branch
  • assets/dashboard.html — the widget, zero deps
  • dev/harness/serve.js + index.html — host imposter
  • test/mcp-text.test.js — text fallback specs

PROTOCOL

Two dialects, one server

  • Host ↔ server: MCP over stdio (JSON-RPC lines)
  • Host ↔ widget: ui/* postMessage dialect
  • Widget's tools/call is proxied by the host
  • Tools declare _meta.ui.resourceUri → widget preloads

DEGRADATION

Capability-aware

  • io.modelcontextprotocol/ui read at call time
  • Apps host → lean text + widget
  • Plain host → aligned glyph tables
  • Same structuredContent either way
